# Glass Currency v2.0

## v2.3 — Kursvergleich и Android

- Большой блок наличного обмена убран с главного экрана.
- Добавлена компактная строка «Сравнение курса», открывающая отдельную Glass-панель.
- Немецкое название заменено с `Bargeldwechsel` на более нейтральное `Kursvergleich`.
- Добавлены PWA-ярлыки калькулятора и сравнения курса по долгому нажатию на иконку.
- Подготовлен отдельный Android-проект с компактным и широким виджетами рабочего стола.

## v2.2 — Встроенный калькулятор

- Добавлена кнопка калькулятора к обоим валютным полям.
- Реализована мобильная Glass-панель с арифметикой, скобками и процентами.
- Поддержаны выражения прямо в полях суммы, включая `65 + 10%` и `120 − 15%`.
- Результат сразу передаётся в выбранное поле и пересчитывает вторую валюту.
- Добавлена локальная история пяти последних вычислений с возможностью очистки.
- Интерфейс калькулятора переведён на русский, украинский, немецкий и английский.

## v2.1 — Android icons, country comparison, languages

- Иконки полностью перерисованы без шрифтовых символов; добавлены отдельные Android maskable-варианты.
- Добавлено сравнение онлайн-курса с официальными курсами покупки/продажи NBP для пар с PLN.
- Для остальных стран доступен ввод курса конкретного обменного пункта и автоматический расчёт разницы.
- Добавлены русский, украинский, немецкий и английский языки с сохранением выбора.
- Основной источник онлайн-курсов переведён на актуальный Frankfurter API v2.

## Интерфейс

- Более глубокий Glass UI с адаптивным фоном, улучшенной типографикой и светлой темой.
- Плавная анимация смены валют, обновления результата и открытия нижней панели.
- Новый экран выбора валют: поиск по коду и названию, крупные touch-зоны, отметка текущей валюты.
- Улучшенная доступность: подписи для элементов управления, поддержка клавиатуры и reduced motion.

## Travel Mode

- Компактные быстрые номиналы и автоматически пересчитываемая таблица.
- Сохранение режима, выбранной пары и последнего курса на устройстве.
- Понятный статус онлайн/офлайн и возраст сохранённых данных.

## Android / Samsung / PWA

- Safe-area отступы, корректная динамическая высота экрана и удобные touch-зоны.
- Маскируемые иконки 192/512, standalone-режим, theme color и ярлыки приложения.
- Подсказка установки через системный PWA-диалог.
- Обновлён service worker и автономный запуск из кэша.

## Данные

- Прямой и обратный расчёт без кнопки «Рассчитать».
- Курсы Frankfurter API; при отсутствии сети используется последний сохранённый курс пары.
